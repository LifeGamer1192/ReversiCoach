# ReversiCoach

リバーシ（オセロ）の上達を支援するゲーム。プレイしながら盤面評価やAIのコメントを通じて、手筋を学べることを目指します。

## ロードマップ

| バージョン | 内容 |
| --- | --- |
| V1 | 1人用オセロのロジックと勝敗判定。AIはルール上置ける場所にランダムに着手。 |
| V2 | プレイヤーの一手ごとに盤面をスコアリングし、どちらが有利かを可視化。AIは次の一手のうち最もスコア期待値が高い場所に着手。 |
| V3 | AIが最大2手先まで読む。難易度選択が可能に。スコアリングの推移をグラフで可視化。 |
| V4 | AIが最大3手先まで読む。プレイヤーの一手ごとに、その手について良し悪しを3行程度でコメント。各手のログ機能を追加。 |
| V5 | AIが最大4手先まで読む。ゲーム終了後にログを解析し、良かった点・悪かった点を15行程度の詳細コメントで提示。 |
| V6 | AIが最大5手先まで読む。1〜5手先読みのAIを難易度選択する際に、コミカルなキャラクター選択を追加。 |
